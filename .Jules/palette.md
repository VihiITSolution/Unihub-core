## 2024-05-18 - Aria labels for password toggle

**Learning:** Missing aria-labels on icon-only toggle buttons is a common accessibility issue across various pages, especially for password visibility toggles.
**Action:** Always check toggle buttons containing only SVGs for aria-labels when implementing or reviewing login and registration pages.
## 2024-05-18 - Aria labels for Custom Toggle Components

**Learning:** Missing aria-labels on icon-only custom switch components built using `<button>` is a common accessibility issue across various pages, especially for settings toggle buttons.
**Action:** Always check toggle buttons and custom switches containing only SVGs or CSS-drawn shapes for aria-labels when implementing or reviewing settings pages.
